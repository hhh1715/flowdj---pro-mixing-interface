# 08 — 銅箔膠帶 + 壓克力原型組裝手冊

> 目標：**一次把 30 個電極全部剪好、貼好、接線好，然後一次跑完 Phase 1–4 測試。**
>
> 本章假設你手邊有：
> - 1 片壓克力板（A4 大小以上、厚度 2–5 mm 皆可）
> - 1 捲銅箔膠帶（寬度 ≥ 5 mm；10–20 mm 最順手）
> - 一包公對公杜邦線（40 條彩色）
> - 美工刀、鋼尺、剪刀、細尖簽字筆
> - 萬用電表（測導通用）
> - 烙鐵 + 焊錫（若要用「焊接法」固定杜邦線；若用「導電銅箔疊壓法」可略）
> - [templates/electrode-template.svg](templates/electrode-template.svg)
>
> 建議時間投資：**第一次做 3–4 小時**（含剪、貼、測）。後續熟練後 1.5 小時。

---

## 為什麼要用「紙上銅箔」這個做法

傳統做法有兩種：

1. **徒手量、徒手剪**：尺寸不準、形狀醜、容易歪。
2. **先在壓克力上畫線、再貼銅箔剪開**：在壓克力上剪銅箔容易刮傷板材，也不容易剪乾淨。

本手冊用的做法：**先把 1:1 樣板印在紙上 → 銅箔貼在紙上 → 沿著紙上的線剪 → 連紙一起撕下 → 貼到壓克力**。

好處：
- 剪出來的形狀就是設計尺寸，不會歪
- 紙是軟的、刀很好切；壓克力是硬的、不好切
- 剪完後銅箔跟紙會分離（因為銅箔膠帶的背膠比紙的纖維黏性強），所以撕的時候紙片會留在桌上、銅箔乾淨貼到壓克力上
- 一次剪完所有電極，不用貼一個剪一個、反覆量

## Phase A — 列印與校正

### A.1 印出樣板

開啟 [templates/electrode-template.svg](templates/electrode-template.svg)。

- 在瀏覽器（Chrome / Edge / Firefox）直接開 SVG → `Ctrl + P` → 印表機選項：
  - **紙張大小：A4**
  - **縮放：100%**（❌ 不要用「符合頁面」「自動縮放」「Fit to Page」）
  - **邊界：預設或最小**
  - **彩色**（方便區分電極類型；黑白也行）

### A.2 量校正方塊（⚠️ 必做）

印出來後，**先拿鋼尺量左下角的「校正方塊」**：

```
┌──────────┐
│          │  ← 這個方塊必須是 10 × 10 mm
│          │    對角線 ≈ 14.14 mm
└──────────┘
```

允許誤差 ±0.3 mm。若量出來是 9.3 × 9.3 mm，代表印表機偷偷縮了 7% — 重印、關掉「符合頁面」。

若多印幾次都不準，可以改用 PDF 轉換後再印（`inkscape electrode-template.svg --export-pdf=template.pdf`），大部分 PDF 閱讀器的「實際尺寸」選項更聽話。

## Phase B — 銅箔貼紙與裁切

### B.1 貼銅箔的順序

**一次貼一個電極，貼完就剪，不要全部貼完才剪**（全部貼完銅箔會擋住你看不到樣板的線）。

基本動作：

1. 撕一段銅箔膠帶，長度略大於要貼的電極。
2. 貼到紙上，完全覆蓋該電極的形狀（連同焊線尾 tail）。
3. 用指甲或塑膠卡片壓平銅箔，排除空氣泡。
4. 用美工刀沿紙上的實線**輕輕**劃過一圈，不要壓太重（壓太重會切斷紙、銅箔會散開）。
5. 用鑷子或指甲從焊線尾掀起一角，把整片銅箔（+背後的一層紙）撕下來。

### B.2 Jog 8 段弧形的處理

Jog 最麻煩，因為是 8 個弧形。**一次處理一段**：

1. 蓋一段銅箔把一個弧形（45° 扇形環）**完全蓋住**（含焊線口）。
2. 沿樣板上的「外圓弧 + 內圓弧 + 2 條放射線」劃 4 刀。
3. 撕下這一段。
4. 換下一段銅箔，繼續下一個弧。

⚠️ 重點：**Jog 的中心（內圓以內）是空心，不要貼銅箔進去**。樣板上有提示「空心 — 不貼」。
中心若貼到銅箔會變成整塊大電極，Jog 演算法會失效。

### B.3 焊線尾（wire tail）

每個電極旁邊都有一個小小的虛線方塊（3–5 mm），代表**焊線尾**：

- 銅箔貼的時候**要連這塊一起貼**，讓電極跟尾巴連成一整片。
- 剪下來後，電極跟尾巴還是黏在一起（因為是同一片銅箔）。
- 之後杜邦線就焊/壓在這個尾巴上，而不是焊在電極主體上（避免焊點佔電極感應面積）。

### B.4 剪完一個電極就**放到分類盒**

剪完一片就貼紙膠帶標籤（寫 `J0`、`T3`、`CUE` 等）黏在銅箔背面。**不要靠記憶**，30 個一混就沒救了。

推薦做法：拿一張 A4 紙畫 30 格，每格寫好 channel 名稱（`M1-Ch0-J0` 之類），剪好的電極直接放進對應格子。

## Phase C — 排版到壓克力板

### C.1 先做版型定位

**在壓克力上先貼遮蔽膠帶（紙膠帶）當輔助線**，用鉛筆或細簽字筆畫出：

- Jog 中心點
- 速度 slider 長邊（118 mm 直線）
- 音量 fader 長邊（58 mm 直線）
- 4 顆 PAD 的四個角
- 3 顆按鈕的位置

畫完再撕掉紙膠帶，線就消失 — 不會在壓克力上留痕。（不想費工就直接用可擦鉛筆畫在壓克力上，酒精 + 衛生紙可擦掉。）

### C.2 貼電極

按照順序貼（**有順序才不會擠在一起**）：

1. **Jog 8 弧** — 從 J0 開始，逆時針 J1, J2, ..., J7。
   - 先貼 J0 和 J2 和 J4 和 J6（對角線那幾個）→ 定位。
   - 再把 J1, J3, J5, J7 補進去。
   - 每一段貼完用指甲壓緊邊緣。
2. **速度 slider** — T0 在最左，T9 在最右，每片間隔 2 mm（用 2 mm 塑膠卡片當間隔器最好）。
3. **音量 fader** — 同 slider 做法。
4. **4 顆 PAD** — 位置依個人喜好，建議排成 2×2 方陣。
5. **3 顆按鈕（CUE / Play / SYNC）** — 通常排在 Play 居中、CUE 左、SYNC 右。

### C.3 排版時的注意

- **電極之間至少留 2 mm** — 距離太近會互相干擾（耦合電容 crosstalk）。
- **焊線尾朝向板子邊緣** — 方便杜邦線接到外圍。
- **Jog 的中心**如果設計要放 LED 或其他東西，現在先貼一張紙膠帶占位，最終版再處理。

## Phase D — 接杜邦線

有兩種做法，**初學者建議用方法 1（導電銅箔疊壓）**，不動烙鐵。

### D.1 方法 1：銅箔疊壓法（不焊）

1. 把杜邦線的一端剝皮 3–5 mm。
2. 把剝皮的線芯**平貼**到電極的焊線尾上。
3. 用另一段銅箔膠帶（小塊 ~5×8 mm）**蓋過**線芯 + 焊線尾，壓緊。
4. 銅箔的黏膠會把線芯夾在兩層銅箔之間，導通靠金屬接觸。
5. 杜邦線另一端插到對應的 MPR121 電極針腳。

**優點：** 免焊、可拆、失敗可重來。
**缺點：** 黏膠老化後接觸電阻會升高 — 這是**測試階段**做法，最終版要焊。

**驗收：** 用萬用電表量「杜邦線另一端 ↔ 電極主體」，導通（≤ 1 Ω）就成功。

### D.2 方法 2：焊接法

1. 杜邦線剝皮 3 mm，預先上錫（鍍錫）。
2. 烙鐵加熱焊線尾（銅箔會吸熱）。
3. 把鍍錫的線芯貼上焊線尾，再點一滴錫熔在一起。

⚠️ 小心：
- **溫度不要太高** — 350°C 以下。溫度太高會燒壞紙 + 銅箔背膠。
- **動作要快** — 2 秒內完成，不要一直烤。
- **壓克力板怕熱** — 銅箔已貼在壓克力上時，下面會傳熱到壓克力。建議**先焊完杜邦線再貼到壓克力**（順序：剪銅箔 → 焊線 → 貼到板子）。

### D.3 線材顏色建議

用 40 條彩色杜邦線做「分色管理」：

| 一束 | 顏色 | 用途 |
|---|---|---|
| 電源 | 紅 / 黑 | Teensy 3.3V → MPR121 3.3V；GND 全部共地 |
| I²C | 黃 / 綠 / 藍 | SDA / SCL / IRQ（IRQ 本專案不接） |
| Jog 8 條 | 灰 / 白系 | J0–J7（每條寫標籤在線上） |
| Tempo 10 條 | 橙 / 黃系 | T0–T9 |
| Volume 5 條 | 綠 / 藍系 | V0–V4 |
| 按鈕 + PAD 7 條 | 紅 / 紫系 | CUE/Play/SYNC/PAD1–4 |

**強烈建議用紙膠帶在每條線上寫標籤**（兩端都貼）。沒標籤 = debug 時你會哭。

## Phase E — 接到 MPR121

電極接哪顆 MPR121 的哪個電極腳，依樣板上的 channel 標示：

| 電極 | MPR121 | Ch |
|---|---|---|
| Jog J0–J7 | **#1** (0x5A) | 0–7 |
| CUE | #1 | 8 |
| Play | #1 | 9 |
| SYNC | #1 | 10 |
| PAD1 | #1 | 11 |
| Tempo T0–T9 | **#2** (0x5B) | 0–9 |
| PAD2 | #2 | 10 |
| PAD3 | #2 | 11 |
| Volume V0–V4 | **#3** (0x5C) | 0–4 |
| PAD4 | #3 | 5 |
| (未使用) | #3 | 6–11 |

## Phase F — 驗收自己的工

全部接完**先別急著上電**，先做下面 3 項純機械檢查：

### F.1 目視檢查

- [ ] 每個電極都有明確邊界，沒有兩個電極「連在一起」
- [ ] Jog 中心**沒**貼銅箔
- [ ] 每個焊線尾都**只有一條**杜邦線
- [ ] 杜邦線標籤兩端都寫了
- [ ] 壓克力表面乾淨，沒有金屬屑

### F.2 萬用電表檢查

用萬用電表「通斷模式」（通就嗶一聲）：

| 量這兩點 | 預期 |
|---|---|
| 杜邦線母頭 ↔ 對應電極本體 | **通**（≤ 1 Ω） |
| 任兩個不同電極之間（例如 J0 ↔ J1） | **不通**（開路） |
| 電極 ↔ 壓克力板 | **不通**（壓克力是絕緣體） |
| MPR121 #1 的 `3.3V` 腳 ↔ `GND` 腳 | **不通**（這條短路 = 上電必燒） |

### F.3 上電前再確認一次

- [ ] MPR121 的 `3.3V` 腳接到 Teensy 的 **3.3V 輸出**，**不是 Vin 5V**（燒 IC 的最常見錯誤）
- [ ] GND 全部共地（Teensy GND ↔ 三顆 MPR121 GND ↔ 所有電極的共地若有）
- [ ] SDA 都接到 Pin 18、SCL 都接到 Pin 19（三顆 MPR121 並聯同一條）
- [ ] ADD 腳：#1 接 GND、#2 接 3.3V、#3 接 SDA（對照 02 章）

確認完 → 插 Teensy USB → 進入 **[06-testing-plan.md](06-testing-plan.md)** 開始跑 Phase 1–4。

## 常見問題

### Q1: 銅箔剪下來後變皺、黏不平

- 撕下時「連紙撕」最好撕 — 紙面朝上、銅箔面朝下，整個翻過來，用手指按壓紙面分離。
- 貼到壓克力後若有氣泡，用塑膠卡片（悠遊卡）從中心往外推。
- 若皺到太嚴重 → 整片報廢，重剪一片（這就是為什麼銅箔膠帶要買一整捲、不要買剛好的量）。

### Q2: 銅箔疊壓的接點過一陣子就鬆

- 黏膠會氧化 / 老化。**這種做法只推薦在測試階段用**。
- 最終版請改焊接 + 絕緣膠帶包覆。
- 臨時急救：剪一段新的銅箔膠帶重新疊壓一次即可。

### Q3: 某個電極 MPR121 讀不到觸碰

優先順序查：

1. 用萬用電表量「杜邦線母頭 ↔ 電極本體」是否通。不通 → 疊壓/焊接不良，重做。
2. 確認杜邦線插對 MPR121 的哪一 Ch。
3. 跑 02 章的 I²C scan，確認三顆 MPR121 都被偵測到（0x5A/0x5B/0x5C）。
4. 調觸控門檻（`setThresholds(12, 6)` → 門檻降低）：[02-mpr121-pinout.md # 觸控門檻](02-mpr121-pinout.md#觸控門檻threshold)

### Q4: 多個相鄰電極會「一起觸發」

電極太靠近 → crosstalk。對策：

- 電極之間間隔增加到 3 mm 以上。
- 或在兩電極之間加一條「接地」的銅箔帶（screen trace）— 把 crosstalk 吸走。
- 或把 MPR121 的 `setDebounces()` 調高。

### Q5: 壓克力板弄髒 / 刮傷怎麼辦

- 壓克力怕酒精會霧化。清潔用**肥皂水 + 軟布**。
- 輕微刮傷可用牙膏 + 軟布打磨（牙膏有細磨料）。
- 嚴重刮傷 → 下次做外殼就包一層 PET / PC 貼片保護層。
